# Assignment 10: File I/O & Algorithmic Search (CSC1015F)

## 📌 Overview
This project was completed as part of the **CSC1015F** Computer Science course at the University of Cape Town. The primary focus was mastering **File I/O operations**, implementing efficient data structures (such as dictionaries and sets), and building algorithmic search routines to solve anagram-matching problems.

---

## 📁 Repository Structure & Attribution

* **`anagramsearch.py`** *(Authored by me)*  
  Handles user input, file parsing, and core search mechanics to look up and display valid anagrams efficiently.
  
* **`anagramsets.py`** *(Authored by me)*  
  Processes text data to group words into sets of anagrams using hash maps and sets for optimized performance.

* **`tracer.py`** *(Course Assignment Component)*  
  A code-tracing utility that assists with debugging by dynamically inserting trace statements at the beginning of function definitions or stripping them out.

* **`testing.py`** *(Provided by UCT Department)*  
  A testing utility framework supplied by the university department to validate output formats and run automated test suites.

---

## 🛠️ Technologies Used
* **Python 3**
* File I/O & Stream Handling
* Algorithmic Complexity Optimization (Dictionaries, Sets)
