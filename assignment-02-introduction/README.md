# Assignment 2: Introduction to Python (CSC1015F)

## 📌 Overview
This introductory assignment focused on getting familiar with Python syntax, editing and testing basic scripts, understanding proper code attribution and plagiarism prevention, unscrambling logic statements, and implementing custom mathematical calculations.

---

## 📁 Repository Structure & Program Details

* **`secret.py`**  
  A classic number-guessing game originally authored by Hussein Suleman. It prompts the user to guess a secret number iteratively, giving concise feedback ("lo" or "hi") until the correct guess is reached.

* **`secret_2.py`**  
  An improved, user-friendly adaptation of the number-guessing game featuring more descriptive dialogue and usability messaging (e.g., "That is way too high. Please try again.").

* **`time.py`**  
  A time-conversion program originally authored by Stephan Jamieson with scrambled statements. It accepts an integer quantity of minutes from the user and correctly calculates and displays the equivalent breakdown in days, hours, and minutes using integer division (`//`) and modulo (`%`) operators.

* **`energy.py`**  
  An independent program that calculates physical energy output based on Einstein's mass-energy equivalence formula, prompting the user for integer values of mass and the speed of light.

## 🛠️ Key Skills & Concepts Emphasized
* **Basic Scripting:** Typing, editing, and executing simple Python programs in an IDE environment.
* **Code Attribution:** Acknowledging original authors (Hussein Suleman, Stephan Jamieson) to maintain academic integrity.
* **Logical Ordering:** Debugging and rearranging out-of-order statements to achieve correct program flow.
* **Arithmetic & Input/Output:** Handling user input, casting data types, and using arithmetic and exponentiation operators.
