# University of Cape Town — CSC1015F Portfolio

Welcome to my coursework repository for **CSC1015F (Computer Science 1M)** at the University of Cape Town (UCT). This repository documents my progression from fundamental scripting and console input/output to advanced modular design, recursion, testing, and algorithmic problem-solving in Python 3.
